Run route builder

Click the map to add waypoints. Drag a pin to move it. Right-click a pin to delete it. Click a coloured leg to change how that section snaps.

Trails leans strongly towards paths and tracks. Roads uses road-bike routing, so it stays on roads. Any path is a balanced walking mix. Straight draws a direct line.

Routing: Valhalla (public FOSSGIS server, no account needed). Elevation: Open-Meteo, about 90 m resolution, so climb is approximate.
